# 忍者之夜 · 规则实现核对文档

本文档记录 `packages/games/night-of-ninja` 裁判的规则依据与核对状态。
主要来源：**RulesPal 完整规则书文本**（rulespal.com/night-of-the-ninja/rulebook）、官方 2 人规则页（brotherwisegames.com）、Zatu how-to-play、One Board Family / BoardGameReview 评测交叉确认。

## ✅ 已按规则书实现（2026-10-15 大修后）

| 规则点 | 实现要点 |
|---|---|
| 人数与身份 | 4–11 人核心（本实现放宽至 3 人）；鹤/莲按人数取排名 1..k（1 最优），奇数人数加浪人；**每轮重发** |
| 轮抽 | 摸 3 选 1 → 余 2 左传 → 再选 1 → **最后 1 张弃到桌面中央**（进入弃牌堆） |
| 暗选 | 手中暗选 1 张扣置；另一张留手（通灵者可见的是**打出的那张**） |
| 夜晚结算顺序 | 类型阶段：间谍→通灵→诡术→盲眼刺客→忍者；**同类型内按卡面角标数字升序**，再按座位 |
| 十三种卡 | 间谍/通灵者/盲眼刺客/忍者（各 6 张，角标 1-6）；六张诡术师：易容师、掘墓人、搅局者、灵商、盗贼、审判官；序外：镜僧、殉道者、主谋 |
| 易容师 | 查看两人身份并**秘密交换**（仅行动者收到定向事件；受害者 identityKnown=false，界面显示「身份不明」） |
| 掘墓人 | 查看弃牌堆（轮抽弃牌），拿一张**立即打出**（需要目标的牌会接着结算）或**收入手牌** |
| 搅局者 | 查看身份，可选择公开 |
| 灵商 | 看一枚代币面值 / 看身份 / 与对方**交换一枚代币** |
| 盗贼 | 公开自己身份，从**代币枚数多于自己**的玩家处拿走一枚（枚数公开、面值保密） |
| 审判官 | 公开自己身份并杀死一人，**无视镜僧与殉道者** |
| 镜僧/殉道者 | 反应：被忍者或盲眼刺客指定时，前者反弹杀死对方，后者获得一枚代币并存活 |
| 主谋 | 身份揭示时存活则家系获胜；**浪人主谋 → 无家系获胜**（仅浪人按存活得分） |
| 荣誉代币 | **面值 2/3/4、暗置抽取**；每人持有代币数组（枚数公开、面值仅本人可见）；先到 **10 分**获胜，同分比数值，完全同分共享 |
| 回合胜负 | 幸存者最佳排名逐位比较；**完全平局 → 每位幸存者各得一枚代币**；获胜家系全员（含死者）得分；浪人存活得分 |
| 死亡 | 不亮身份；未结算的牌作废保持暗置；可以继续聊天嘴炮 |

## ⏳ 仍待实体盒核对的细节（拿到实物后 5 分钟）

1. **牌堆构成**：规则书只说 33 张，未公开逐张清单——暂按「间谍/通灵/盲眼刺客/忍者各 6 + 六诡术师 + 三特殊 = 33」。
2. **代币面值比例**：35 枚、面值 2/3/4，比例未公开——暂按 12/12/11。
3. **角标数字分配**：多副本卡的角标暂按 1-6 顺序分配。
4. **同角标同类型的并列**：暂按座位顺序。
5. **实现简化**：易容师不可选择「只看不换」；灵商的三种操作以变体按钮呈现而非顺序抉择。
6. 2 人变体（每人操控 3 张家系牌）未实现。

核对后只需修改 `cards.ts` 数据表与（如涉及）`referee.ts` 对应分支。
