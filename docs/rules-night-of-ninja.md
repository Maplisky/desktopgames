# 忍者之夜 · 规则实现核对文档

本文档记录 `packages/games/night-of-ninja` 裁判的规则依据与核对状态。
主要来源：**RulesPal 完整规则书文本**（rulespal.com/night-of-the-ninja/rulebook）、Zatu how-to-play、官方 2 人规则页（brotherwisegames.com）、One Board Family / BoardGameReview 评测——**多源交叉验证**。

## 🔴 重大修正（2026-10-15 第二次全面核对）

**夜晚流程**：最初实现误读为「全员同时暗选 → 依次翻开」。经 Zatu（"phases are called one by one"、"play it face up in front of you"、"Once everyone has done this"）、RulesPal（"If nobody reveals in a phase, skip it. Skipped cards cannot be played later that round"）与评测（"players can choose not to play a ninja card to try and bluff"）三源交叉确证，真实规则为：

- 夜晚**逐类型阶段叫名**（间谍 → 通灵 → 诡术 → 盲眼刺客 → 忍者）；
- 每个阶段，持有该类型牌的玩家**决定是否打出**：打出立即面朝上公开；不打出则该牌本夜作废；
- 全部决定后，已打出的牌**按角标数字升序**结算（同角标按座位）；
- 通灵者看的是目标**手牌**（打出的牌本就公开）；
- 镜僧/殉道者是**从手牌打出的反应牌**（被刺杀宣告时立即抉择）；主谋是计分时从手牌揭示的持牌。

已按此重构（`non:phasePlay` / `non:phasePass` / `non:react` / `non:noReact` 动作，夜晚状态机 = 窗口/结算队列/待反应三态）。

## ✅ 已按规则书实现（多源交叉验证后）

| 规则点 | 实现要点 |
|---|---|
| 人数与身份 | 4–11 人核心（本实现放宽至 3 人）；鹤/莲按人数取排名 1..k（1 最优），奇数人数加浪人；**每轮重发** |
| 轮抽 | 摸 3 选 1 → 余 2 左传 → 再选 1 → **最后 1 张弃到桌面中央**（进入弃牌堆） |
| 夜晚 | 逐类型阶段叫名，从手牌决定打出（立即公开）或保留（作废）；窗口关闭后按角标升序结算；被杀者未结算的牌作废；唯一存活者打出的刺杀牌无目标自动跳过 |
| 夜晚结算顺序 | 类型阶段：间谍→通灵→诡术→盲眼刺客→忍者；**同类型内按卡面角标数字升序**，再按座位 |
| 十三种卡 | 间谍/通灵者/盲眼刺客/忍者（各 6 张，角标 1-6）；六张诡术师：易容师、掘墓人、搅局者、灵商、盗贼、审判官；序外：镜僧、殉道者、主谋 |
| 易容师 | 查看两人身份并**秘密交换**（仅行动者收到定向事件；受害者 identityKnown=false，界面显示「身份不明」） |
| 掘墓人 | 查看弃牌堆（轮抽弃牌），拿一张**立即打出**（需要目标的牌会接着结算）或**收入手牌** |
| 搅局者 | 查看身份，可选择公开 |
| 灵商 | 看一枚代币面值 / 看身份 / 与对方**交换一枚代币** |
| 盗贼 | 公开自己身份，从**代币枚数多于自己**的玩家处拿走一枚（枚数公开、面值保密） |
| 审判官 | 公开自己身份并杀死一人，**无视镜僧与殉道者** |
| 镜僧/殉道者 | 反应：被忍者或盲眼刺客指定时，前者反弹杀死对方，后者获得一枚代币并存活 |
| 主谋 | 身份揭示时存活则家系获胜；**浪人主谋 → 无家系获胜**（仅浪人按存活得分） |
| 荣誉代币 | **面值 2/3/4、暗置抽取**；每人持有代币数组（枚数公开、面值仅本人可见）；先到 **10 分**获胜，同分比数值，完全同分共享 |
| 回合胜负 | 幸存者最佳排名逐位比较；**完全平局 → 每位幸存者各得一枚代币**；获胜家系全员（含死者）得分；浪人存活得分 |
| 死亡 | 不亮身份；未结算的牌作废保持暗置；可以继续聊天嘴炮 |

## ⏳ 仍待实体盒核对的细节（拿到实物后 5 分钟）

1. **牌堆构成**：规则书只说 33 张，未公开逐张清单——暂按「间谍/通灵/盲眼刺客/忍者各 6 + 六诡术师 + 三特殊 = 33」。
2. **代币面值比例**：35 枚、面值 2/3/4，比例未公开——暂按 12/12/11。
3. **角标数字分配**：多副本卡的角标暂按 1-6 顺序分配。
4. **同角标同类型的并列**：暂按座位顺序。
5. **实现简化**：易容师不可选择「只看不换」；灵商的三种操作以变体按钮呈现而非顺序抉择；掘墓人对无目标类牌（镜僧/殉道者/主谋）只允许「收下手牌」不可立即打出。
6. 2 人变体（每人操控 3 张家系牌）未实现。

## 🛡 检错修复记录（2026-10-15 多轮检错）

1. **夜晚死锁防护**：需要目标的卡在无合法目标时（如唯一存活者打出忍者/间谍、易容师仅剩一名其他存活者）自动跳过该牌，不再永久等待。
2. **夜晚计时器**：超时时钟从「阶段级」改为「结算者级」——夜晚内每个玩家的抉择独立计时，断线玩家不再卡死整局。
3. **掘墓人打出校验**：无目标类牌从弃牌堆只能收下（legalActions 与 resolve 双重校验），防止主谋/反应牌被打出后效果丢失。
4. **错误码残留**：加入房间失败后错误码未清除会导致之后加入任何新房间被立即弹回大厅——收到房间视图时清除。
5. **UI 选择残留**：变体操作方式（搅局者/灵商）在结算者切换时自动重置。
6. **回归验证**：73 项自动化测试（裁判 66 含 36 局模糊测试 + 服务端 7 含 seq 幂等）+ 浏览器整局回归无卡死。

### 第二轮全面检错（同日）

7. **信息泄露**：掘墓人「收下」弃牌时牌 id 曾公开广播——现公开事件仅含动作，牌 id 定向发给本人（弃牌在实体规则中是扣置的）。
8. **超时垫步保守化**：垫步优先「跳过 > 放过 > 默认」，不再替 AFK 玩家激进打出刺杀牌或强制偷取。
9. **易容师自涉交换**：易容师把自己换入交换对时仍知道自己新身份（他亲眼看过两张牌），仅其他被换者失知。
10. **灵商换代币校验**：双方都持有代币才可交换（合法选项与校验双向收紧）。
11. **展示补全**：座位上显示各玩家代币枚数（公开信息，盗贼Targeting依据）；中央结算卡恢复显示角标数字。
12. **加入失败自动回大厅**：对局已开始/房间已满与房间不存在同样处理，不再滞留占位页。
13. **终验**：75 项自动化测试全绿 + 浏览器整局回归（5 轮无卡死）。

核对后只需修改 `cards.ts` 数据表与（如涉及）`referee.ts` 对应分支。
